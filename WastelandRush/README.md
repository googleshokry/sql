# Wasteland Rush 🚗🧟 — Unity 3D

لعبة أصلية من نوع "سوق العربية وسط الزومبي، اكسب فلوس، طوّر عربيتك" مع عناصر **Roguelike**.

## فكرة اللعبة
- بتسوق عربية في طريق صحراوي مليان تلال ومطبات (ramps) وزومبي.
- كل رحلة (Run) هدفها توصل **لنقطة الإخلاء (Evacuation)** في آخر الطريق.
- البنزين محدود → لو خلص البنزين أو العربية اتكسرت أو اتقلبت، الرحلة بتنتهي.
- بتكسب فلوس من: **المسافة** + **قتل الزومبي** + **بونص الوصول**.
- في **الجراج** بتشتري ترقيات دائمة: Engine, Fuel Tank, Armor, Nitro, Suspension, Roof Turret.
- **Roguelike:** كل 300 متر فيه **Supply Drop** بيوقف اللعبة ويديك 3 اختيارات عشوائية من 12 Perk
  (Spiked Ram, Turbocharger, Blood Money, Gyroscope, ...) — بتفضل معاك في الرحلة دي بس.
- كل ما توصل للإخلاء، **الـ Stage بيزيد**: طريق أطول، زومبي أكتر، Brutes أكتر، ramps أعلى.

### أنواع الزومبي
| النوع | الوصف |
|------|-------|
| Walker | عادي وبطيء |
| Runner | سريع |
| Brute | ضخم وتقيل، محتاج سرعة عالية عشان تخبطه |

لو العربية وقفت وسط مجموعة زومبي، هيفضلوا يضربوها لحد ما تتكسر!

## التحكم
| الزرار | الوظيفة |
|------|---------|
| D / → | بنزين |
| A / ← | فرامل / رجوع |
| W / S | تميل العربية في الهوا (عشان تنزل على العجل) |
| Space / Shift | Nitro |
| R | إنهاء الرحلة |

## طريقة التشغيل
1. افتح **Unity Hub** واعمل مشروع جديد **3D (Built-In Render Pipeline)** — يشتغل كمان مع URP.
   (اتجرب على Unity 2021.3+ ويدعم Unity 6.)
2. انسخ فولدر `Assets/Scripts` من هنا وحطه جوه فولدر `Assets` في مشروعك.
3. افتح أي Scene (حتى الـ SampleScene الفاضية) ودوس **Play** ▶️

خلاص! مش محتاج تعمل أي Prefab أو Scene setup — اللعبة بتبني نفسها أوتوماتيك
(`RuntimeInitializeOnLoadMethod`): الأرض، العربية، الزومبي، الكاميرا، الإضاءة، والـ UI.

> بتشتغل مع الـ Input Manager القديم ومع الـ Input System الجديد.
> الحفظ بيتم أوتوماتيك في `PlayerPrefs`.

## هيكل الكود
| الملف | الوظيفة |
|------|---------|
| `GameManager.cs` | Bootstrap، حالات اللعبة (Garage / Run / Perk / Results)، الفلوس، الحفظ |
| `CarController.cs` | فيزيا العربية (raycast suspension)، بنزين، HP، Nitro، تحكم في الهوا |
| `LevelGenerator.cs` | توليد الأرض procedural (Perlin + ramps) في chunks، وتوزيع الزومبي والحاجات |
| `Zombie.cs` | الزومبي: مطاردة، هجوم، ragdoll لما تخبطه |
| `Turret.cs` | رشاش فوق العربية بيضرب أوتوماتيك |
| `Pickup.cs` | جراكن البنزين، Supply Drop، نقطة الإخلاء |
| `Progression.cs` | الترقيات، الأسعار، الـ Perks |
| `GameUI.cs` | الواجهة كلها (OnGUI) |
| `CameraFollow.cs` | كاميرا جانبية بتزوّم مع السرعة |
| `Util.cs` | Materials، Input، توافق إصدارات Unity |
