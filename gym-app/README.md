# نظام إدارة الجيم — Gym Manager

نظام متكامل لإدارة الصالات الرياضية مبني بـ **Laravel 12 + Filament 4 + MySQL**، يعمل بـ **العربية (RTL) والإنجليزية** (زر 🌐 لتبديل اللغة)، ومعه **تطبيق موبايل iOS و Android** في مجلد [`../mobile-app`](../mobile-app/README.md).

## المميزات

### العضويات
- **المشتركين**: صورة، كود عضوية تلقائي (للكارت/الباركود)، الرقم القومي، تاريخ الميلاد، المدرب المسؤول، بيانات صحية وهدف التمرين، رقم طوارئ، حظر مشترك مع ذكر السبب.
- **ملف المشترك**: حالة الاشتراك، الأيام والحصص المتبقية، المبلغ المتبقي عليه، سجل الاشتراكات والمدفوعات والحضور، **القياسات الجسمية** (وزن، دهون، عضلات، BMI...).
- **الباقات**: مدة بالأيام، سعر، عدد حصص (أو غير محدود)، أيام تجميد مسموحة، دعوات ضيوف، باقات بمدرب خاص.
- **الاشتراكات**: بيع / تجديد (التجديد يبدأ تلقائياً بعد انتهاء الاشتراك الحالي)، خصم، دفع جزئي ومتابعة المتبقي، **تجميد وفك تجميد** مع تعديل تاريخ الانتهاء تلقائياً، إلغاء، تحديث تلقائي للحالة (ساري / مجمد / منتهي / لم يبدأ).
- تبويبات سريعة: ساري، ينتهي قريباً، منتهي، مجمد، بدون اشتراك + فلاتر متعددة + بحث شامل (Ctrl+K).
- تصدير المشتركين إلى Excel (CSV) وطباعة **كارنيه بباركود**.
- تذكير بالتجديد عبر **واتساب** برسالة قابلة للتعديل.

### الحضور والانصراف
- شاشة استقبال سريعة: امسح الكارت (باركود) أو اكتب الكود / الموبايل / الاسم ← دخول، والمسح مرة أخرى ← خروج.
- تحقق تلقائي: اشتراك منتهي، مجمد، حصص منتهية، مشترك محظور، مديونية (حسب الإعدادات)، ومع إمكانية **السماح الاستثنائي** للمدير.
- عرض صورة المشترك وبياناته وتنبيه الملاحظات الطبية وعيد الميلاد.
- قائمة المتواجدين الآن، سجل حضور كامل بالمدة، دخول ضيوف (دعوات)، خروج تلقائي بعد عدد ساعات.

### المالية
- المدفوعات بإيصالات مرقمة قابلة للطباعة (كاش، فيزا، محافظ إلكترونية، إنستاباي، تحويل بنكي).
- المصروفات وبنودها مع إرفاق فواتير.
- **التقارير**: إيرادات حسب طريقة الدفع والنوع، مصروفات حسب البند، صافي الربح، المبيعات وأرباحها، الاشتراكات حسب الباقة، عمولات المدربين، المديونيات، ساعة الذروة — مع فترات جاهزة (اليوم، الأسبوع، الشهر...) وطباعة.

### المتجر والبوفيه
- منتجات بمخزون وسعر تكلفة وبيع وتنبيه عند انخفاض المخزون.
- نقطة بيع بفواتير متعددة الأصناف تخصم من المخزون تلقائياً، وطباعة فاتورة.

### الإدارة
- المدربين (مرتب ونسبة عمولة).
- المستخدمين والصلاحيات: **مدير النظام**، **مدير الجيم**، **موظف استقبال** (لا يرى المالية والتقارير والإعدادات).
- إعدادات الجيم: الاسم، الشعار، العملة، أيام التنبيه قبل الانتهاء، رسالة واتساب، تذييل الإيصال...
- لوحة تحكم: إحصائيات لحظية، رسم بياني للإيرادات والمصروفات والحضور، اشتراكات تنتهي قريباً، مديونيات.

## التشغيل

المتطلبات: PHP 8.2+، Composer، MySQL 8 أو MariaDB.

```bash
cd gym-app
composer install
cp .env.example .env
php artisan key:generate
# عدّل بيانات قاعدة البيانات في .env (DB_DATABASE, DB_USERNAME, DB_PASSWORD)
php artisan migrate --seed
php artisan storage:link
php artisan serve
```

افتح: `http://localhost:8000/admin`

| المستخدم | البريد | كلمة المرور |
|---|---|---|
| مدير النظام | admin@gym.com | password |
| موظف استقبال | reception@gym.com | password |

> غيّر كلمات المرور فوراً من شاشة المستخدمين. البيانات التجريبية (مشتركين، مدربين، منتجات) تُضاف فقط عندما يكون `APP_ENV=local`.

### المهام المجدولة
لتحديث حالة الاشتراكات يومياً والخروج التلقائي، أضف إلى cron:

```
* * * * * cd /path/to/gym-app && php artisan schedule:run >> /dev/null 2>&1
```

أو شغّلها يدوياً: `php artisan gym:refresh-subscriptions` و `php artisan gym:auto-checkout`.

### قارئ الباركود
أي قارئ باركود USB يعمل كلوحة مفاتيح: افتح شاشة **تسجيل الدخول والخروج** وامسح كارت المشترك مباشرة.

## اللغات

- كل نصوص الواجهة مكتوبة بالعربي داخل `__()`، والترجمة الإنجليزية في `lang/en.json`، ورسائل التحقق العربية في `lang/ar/`.
- كل مستخدم يحفظ لغته المفضلة. التبديل من زر 🌐 أعلى الصفحة أو قائمة المستخدم أو صفحة الدخول.
- لإضافة نص جديد: اكتبه `__('النص بالعربي')` ثم أضف ترجمته في `lang/en.json`.

## API تطبيق الموبايل

المسار: `/api/v1` — أرسل `Accept-Language: ar` أو `en`، و `Authorization: Bearer <token>` للمسارات المحمية.

| المسار | الوصف |
|---|---|
| `GET /gym`, `GET /plans`, `GET /announcements` | بيانات الجيم والباقات والإعلانات (بدون تسجيل دخول) |
| `POST /auth/member/login` | `login` (كود أو موبايل) + `password` ← توكن المشترك |
| `POST /auth/staff/login` | `email` + `password` ← توكن الموظف |
| `POST /auth/logout` | تسجيل الخروج |
| `GET /member/home`, `/member/me`, `/member/subscriptions`, `/member/attendances`, `/member/payments`, `/member/measurements` | بيانات المشترك |
| `PUT /member/profile`, `POST /member/password` | تعديل البيانات وكلمة المرور |
| `GET /staff/dashboard`, `/staff/inside`, `/staff/members?search=` | للموظف |
| `POST /staff/checkin` | `code` (من QR/باركود) ← دخول أو خروج، و `force` للسماح الاستثنائي (للمدير) |
| `POST /staff/attendances/{id}/checkout` | تسجيل خروج |

كلمة مرور التطبيق للمشترك: من ملف المشترك ← **دخول التطبيق** (تُنشأ وتُرسل على واتساب)، أو من نموذج التعديل.
الإعلانات التي تظهر في التطبيق: **العضويات ← إعلانات التطبيق**. بيانات الجيم في التطبيق: **الإعدادات**.
