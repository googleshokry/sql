# تطبيق Gym Manager للموبايل (iOS و Android)

تطبيق واحد لـ **iOS و Android** مبني بـ **React Native (Expo SDK 58) + TypeScript**، ومربوط بسيستم الجيم (Laravel) عن طريق الـ API.
يدعم **العربية (من اليمين لليسار)** و **English**، ويختار لغة الموبايل تلقائياً أول مرة، ويمكن تغييرها من داخل التطبيق.

## الشاشات

**للمشترك**
- **الرئيسية**: الاشتراك الحالي (الأيام والحصص المتبقية، التجميد، الدعوات، المبلغ المتبقي)، الزيارات وآخر 7 أيام، أخبار وعروض الجيم.
- **الكارت**: كارنيه رقمي بـ **QR** يحمل كود العضوية — يعرضه على الاستقبال (نفس كود الكارت المطبوع).
- **السجل**: الحضور، المدفوعات، الاشتراكات السابقة، القياسات.
- **حسابي**: البيانات، اللغة، بيانات الجيم (مواعيد، عنوان، اتصال، خريطة)، تغيير كلمة المرور، تسجيل الخروج.

**للموظف (الاستقبال)**
- **مسح**: مسح QR/باركود المشترك بالكاميرا (أو كتابة الكود) لتسجيل الدخول/الخروج، مع إحصائيات اليوم والسماح الاستثنائي للمدير.
- **بالداخل**: المتواجدون الآن مع تسجيل الخروج.
- **المشتركين**: بحث بالاسم/الكود/الموبايل وتسجيل دخول/خروج.

## التشغيل للتطوير

```bash
cd mobile-app
npm install
EXPO_PUBLIC_API_URL=http://192.168.1.10:8000 npx expo start
```

- استخدم عنوان IP الكمبيوتر على الشبكة (ليس `localhost`) حتى يصل الموبايل للسيرفر، وشغّل Laravel بـ `php artisan serve --host=0.0.0.0`.
- اضبط `APP_URL` في ملف `.env` للسيستم على نفس العنوان حتى تظهر صور المشتركين في التطبيق.
- يمكن أيضاً تغيير عنوان السيرفر من شاشة الدخول (⚙️ عنوان السيرفر).
- مسح الكاميرا يحتاج **development build** (`npx expo run:android` أو `npx expo run:ios`) أو تطبيق Expo Go.

## دخول المشترك

التطبيق واحد لكل الجيمات على المنصة: المشترك يكتب **كود الجيم** (مثل `champions`) ثم كود العضوية أو الموبايل وكلمة المرور.
الموظف يكفيه البريد وكلمة المرور لو يعمل في جيم واحد، ويكتب كود الجيم لو يعمل في أكثر من فرع.

من لوحة التحكم: افتح ملف المشترك ← **دخول التطبيق** ← يتم إنشاء كلمة مرور وإرسالها له على واتساب.
أو اكتب **كلمة مرور التطبيق** في نموذج تعديل المشترك. المشترك يدخل بكود العضوية أو الموبايل + كلمة المرور.

الموظفون يدخلون بنفس بريد وكلمة مرور لوحة التحكم.

## البناء والنشر على المتاجر (EAS)

1. عدّل `EXPO_PUBLIC_API_URL` في `eas.json` إلى رابط السيستم الحقيقي (HTTPS).
2. عدّل `name` و `ios.bundleIdentifier` و `android.package` في `app.json`، وضع الأيقونات في `assets/`.
3. ثم:

```bash
npx eas-cli@latest login
npx eas-cli@latest build --profile preview --platform android     # ملف APK للتجربة
npx eas-cli@latest build --profile production --platform all      # للنشر على Google Play و App Store
npx eas-cli@latest submit --platform all
```

## الأوامر

```bash
npm run typecheck   # فحص TypeScript

npm run export:web  # نسخة ويب (للتجربة)
```

