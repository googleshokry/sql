# Smart ERP — نظام محاسبة وإدارة موارد متكامل (Laravel + Filament + MySQL)

نظام **عربي / إنجليزي** (RTL و LTR) + **تطبيق أندرويد** متصل بنفس السيستم، يجمع مميزات برامج **دفترة (Daftra)** و **تميز الرواد** و **Dexef** في برنامج واحد،
مبني بـ **Laravel 13** و **Filament 5** وقاعدة بيانات **MySQL / MariaDB**.

---

## المميزات

| الوحدة | المميزات |
|---|---|
| **المبيعات** | فواتير مبيعات ضريبية، عروض أسعار (تتحول لفاتورة بضغطة)، مرتجعات مبيعات (إشعار دائن)، قوائم أسعار قطاعي/جملة، خصم على السطر وعلى الفاتورة، شحن، حالة السداد (مدفوعة / جزئي / غير مدفوعة) |
| **نقطة البيع POS** | شاشة كاشير سريعة، بحث وقراءة باركود، بيع نقدي أو آجل، حساب الباقي، طباعة إيصال حراري 80mm |
| **التقسيط** (Dexef) | تقسيط الفاتورة مباشرة أو خطة مستقلة، مقدم، فائدة، أقساط شهرية/أسبوعية، ضامن، تحصيل القسط بسند قبض تلقائي، تنبيه الأقساط المتأخرة |
| **العملاء و CRM** | ملف العميل، الرصيد اللحظي، حد ائتمان، كشف حساب، متابعات ومواعيد (مكالمة/زيارة/اجتماع) |
| **المشتريات** | أوامر شراء ← فواتير مشتريات ← مرتجعات، الموردين وأرصدتهم وكشوف حساباتهم |
| **المخزون** | أصناف وخدمات، تصنيفات، وحدات، باركود وطباعة ملصقات، مخازن متعددة، تحويلات مخزنية، جرد وتسوية، رصيد أول المدة، **متوسط التكلفة المرجح**، حد الطلب، سجل حركة الصنف، منع البيع بالسالب (قابل للتعديل) |
| **المالية** | خزائن وبنوك ومحافظ، سندات قبض وصرف، تحويل بين الخزائن، المصروفات وبنودها مع الضريبة والمرفقات |
| **المحاسبة** | دليل حسابات شجري جاهز، **قيود آلية** لكل عملية (فواتير، مرتجعات، سندات، مصروفات، رواتب، جرد)، قيود يومية يدوية مع التحقق من التوازن |
| **التقارير** | كشف حساب عميل/مورد، دفتر الأستاذ، ميزان المراجعة، قائمة الدخل، الميزانية العمومية، الإقرار الضريبي VAT، المبيعات والأرباح (حسب الصنف/العميل/البائع/اليوم/التصنيف)، تقييم المخزون، أعمار الديون |
| **الموارد البشرية** | الموظفين، الأقسام، الحضور والانصراف، الإجازات، السلف (تخصم من الراتب)، مسير رواتب شهري يحسب العمولات وخصم الغياب والسلف ويُرحّل محاسبياً |
| **الفوترة الإلكترونية** | فاتورة ضريبية / مبسطة مع **رمز QR متوافق مع هيئة الزكاة والضريبة (ZATCA - المرحلة الأولى)**، المبلغ بالحروف (تفقيط)، فاتورة A4 وإيصال حراري |
| **الإعدادات والصلاحيات** | بيانات المنشأة والشعار، العملة (ر.س، ج.م، د.إ ...)، نسبة الضريبة، فروع متعددة، مستخدمين بأدوار: مدير، مدير فرع، محاسب، كاشير، مشتريات، أمين مخزن، موارد بشرية |
| **لوحة التحكم** | مبيعات اليوم والشهر، صافي الربح، أرصدة الخزائن، الذمم، رسم بياني 12 شهر، أحدث الفواتير، نواقص المخزون، الأقساط المستحقة، المتابعات القادمة |

### دورة المستند
كل مستند (فاتورة، مرتجع، تحويل، جرد، مسير رواتب) يُحفظ **مسودة** ثم **يُرحّل**:
عند الترحيل يتم تحريك المخزون وإنشاء القيد المحاسبي تلقائياً، ويُقفل المستند ضد التعديل.
يمكن للمدير/المحاسب **إلغاء الترحيل** لعكس الحركات والقيود.

## التثبيت

المتطلبات: PHP 8.3+، Composer، MySQL 8 أو MariaDB 10.6+

```bash
git clone <repo> smart-erp && cd smart-erp
composer install
cp .env.example .env
php artisan key:generate

# عدّل بيانات قاعدة البيانات في .env
# DB_DATABASE=erp  DB_USERNAME=root  DB_PASSWORD=
mysql -u root -e "CREATE DATABASE erp CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci"

php artisan migrate --seed          # ينشئ الجداول ودليل الحسابات والمستخدم الافتراضي
php artisan storage:link
php artisan serve
```

افتح: `http://localhost:8000/admin`

| البريد | كلمة المرور |
|---|---|
| `admin@admin.com` | `password` |

> **غيّر كلمة المرور فور الدخول.**
> بيانات تجريبية (أصناف وعملاء وفاتورة مشتريات) تُضاف تلقائياً في بيئة `local`.
> للتحكم: `SEED_DEMO_DATA=false php artisan migrate:fresh --seed`

بعد الدخول: **الإعدادات ← إعدادات الشركة** وأدخل اسم المنشأة والرقم الضريبي والشعار.

## اللغات (عربي / English)

- من قائمة المستخدم (أعلى الشاشة) اضغط **English / العربية** للتبديل، ويُحفظ اختيار كل مستخدم.
- الطباعة (الفواتير والسندات) تطلع بلغة المستخدم، والمبلغ بالحروف عربي أو إنجليزي.
- الترجمة الإنجليزية في `lang/en.json` (المفتاح هو النص العربي) — لإضافة نص جديد اكتبه بـ `__('النص')` وأضف ترجمته.

## تطبيق الأندرويد (`mobile/`)

تطبيق Flutter عربي/إنجليزي يتصل بنفس السيستم عبر الـ API:

| الشاشة | المحتوى |
|---|---|
| الرئيسية | مبيعات اليوم والشهر، صافي الربح، الخزائن، المستحقات، رسم آخر 7 أيام، أحدث الفواتير |
| بيع | بحث بالأصناف، **مسح الباركود بالكاميرا**، سلة، خصم، اختيار عميل (أو إضافة عميل جديد)، دفع كامل/جزئي/آجل، الفاتورة تُرحّل فوراً |
| الفواتير | بحث وفلترة بحالة السداد، تفاصيل الفاتورة، تحصيل دفعة، طباعة A4 أو إيصال حراري / مشاركة |
| العملاء | بحث، إضافة عميل، كشف حساب بالرصيد الجاري، سند قبض مع طباعته، اتصال بالعميل |
| المزيد | الأصناف والأرصدة، سندات القبض، المصروفات (إضافة مصروف)، تغيير اللغة، تسجيل الخروج |

**التشغيل:** ثبّت ملف `smart-erp.apk` على الموبايل، وعند الدخول اكتب رابط السيرفر (مثال `https://erp.mycompany.com`)
وبريد وكلمة مرور أي مستخدم من شاشة المستخدمين.
> لو السيرفر على جهازك في نفس الشبكة استخدم IP الجهاز: `php artisan serve --host=0.0.0.0` ثم `http://192.168.1.10:8000`

**بناء الـ APK بنفسك:**
```bash
cd mobile
flutter pub get
flutter build apk --release      # الناتج: build/app/outputs/flutter-apk/app-release.apk
```
> الـ APK الحالي موقّع بمفتاح التطوير (debug key) ويصلح للتثبيت المباشر. للنشر على Google Play أنشئ keystore خاص بك
> وأضفه في `android/app/build.gradle.kts` (لا ترفع الـ keystore على GitHub).

## الـ API (للتطبيق أو أي ربط خارجي)

المصادقة بـ Bearer Token (Laravel Sanctum). اللغة تُحدد بالهيدر `Accept-Language: ar` أو `en`.

| Method | Endpoint | الوصف |
|---|---|---|
| POST | `/api/v1/auth/login` | `{email, password, device_name}` ← `{token, user}` |
| GET | `/api/v1/auth/me` · PUT `/auth/locale` · POST `/auth/logout` | المستخدم واللغة والخروج |
| GET | `/api/v1/lookups` | بيانات الشركة، العملة، المخازن، الخزائن، طرق الدفع، بنود المصروفات |
| GET | `/api/v1/dashboard` | مؤشرات لوحة التحكم |
| GET | `/api/v1/products?search=&warehouse_id=&price_list=` · `/products/barcode/{code}` | الأصناف والأرصدة |
| GET/POST | `/api/v1/customers` · GET `/customers/{id}` · `/customers/{id}/statement?from=&to=` | العملاء وكشف الحساب |
| GET/POST | `/api/v1/sales-invoices` · GET `/sales-invoices/{id}` · POST `/sales-invoices/{id}/payments` | الفواتير (الإنشاء يرحّل ويحصّل) |
| GET/POST | `/api/v1/payments` · `/api/v1/expenses` | سندات القبض والمصروفات |

كل فاتورة وسند يرجع معه `print_url` (رابط طباعة موقّع صالح 7 أيام).

## هيكل الكود

```
app/
├── Models/                 # الموديلات + Concerns (ترقيم تلقائي، مستندات ذات بنود، سداد)
├── Services/
│   ├── Accounting.php      # إنشاء القيود الآلية والتحقق من توازنها
│   ├── Inventory.php       # حركات المخزون ومتوسط التكلفة
│   └── Posting.php         # ترحيل/إلغاء ترحيل المستندات والتحويل بينها
├── Support/                # حساب الإجماليات، ZATCA QR، التفقيط
├── Filament/
│   ├── Support/DocumentResource.php   # أساس مشترك لكل شاشات الفواتير
│   ├── Resources/          # كل الشاشات
│   ├── Pages/              # نقطة البيع، الإعدادات، التقارير
│   └── Widgets/            # لوحة التحكم
└── Http/Controllers/PrintController.php  # الطباعة
database/seeders/ChartOfAccountsSeeder.php # دليل الحسابات الافتراضي
```
