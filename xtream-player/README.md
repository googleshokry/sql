# Xtream Player 📺

مشغّل IPTV لسيرفرات **Xtream Codes** بنسختين:

| النسخة | الجهاز | طريقة التشغيل |
|---|---|---|
| **نسخة التلفزيون** | شاشة توشيبا / هايسنس بنظام **VIDAA** | تطبيق ويب (HTML5) يُفتح من متصفح الشاشة، ويتحكم فيه بالريموت |
| **نسخة الموبايل** | أندرويد (APK) — ويشتغل كمان على Android TV | تطبيق Capacitor بمشغّل أصلي **ExoPlayer** |

الكود واحد (مجلد `www`) والنسختين بيشتغلوا منه.

## المميزات
- تسجيل دخول بـ (السيرفر + اسم المستخدم + كلمة المرور) أو بلصق **رابط M3U** كامل
- حفظ أكثر من حساب
- القنوات المباشرة + الأفلام + المسلسلات (مواسم وحلقات)
- تصنيفات + بحث + مفضلة ⭐
- دليل البرامج (EPG): البرنامج الحالي والتالي
- تقليب القنوات بالأسهم ▲▼ أو أزرار CH+/CH-
- استكمال الفيلم/الحلقة من آخر مكان وقفت عنده
- تحكم كامل بالريموت (أسهم / OK / رجوع / تشغيل / إيقاف / تقديم)
- الزر الأحمر على الريموت (أو الضغط المطوّل على الموبايل) = إضافة للمفضلة
- على الموبايل: مشغّل ExoPlayer يدعم m3u8 و ts و mp4 و mkv

## 1) نسخة شاشة VIDAA (توشيبا)

شاشات VIDAA مش بتسمح بتثبيت ملفات تطبيقات بشكل مباشر، فالطريقة العملية إن التطبيق يشتغل من **سيرفر صغير على الشبكة المنزلية** والشاشة تفتحه من المتصفح.

### الخطوات
1. على أي كمبيوتر أو لابتوب (أو موبايل أندرويد بتطبيق Termux) متوصل بنفس الراوتر، نزّل [Node.js](https://nodejs.org) (نسخة 18 أو أحدث).
2. شغّل:
   ```bash
   cd xtream-player
   node proxy/server.js
   ```
   هيظهر لك رابط زي: `http://192.168.1.10:8080`
3. على الشاشة افتح **المتصفح (Browser)** من قائمة التطبيقات واكتب الرابط ده، وبعدين احفظه في المفضلة.
4. ادخل بيانات اشتراك الـ Xtream وابدأ المشاهدة.

> السيرفر ده بيشتغل كمان **بروكسي** تلقائياً، فبيحل مشكلة CORS اللي بتمنع متصفح الشاشة من الاتصال بسيرفرات IPTV كتير. لو فتحت التطبيق من مكان تاني (استضافة خارجية مثلاً) اكتب رابط البروكسي يدوياً من **الإعدادات**.

### أزرار الريموت
| الزر | الوظيفة |
|---|---|
| الأسهم | التنقل |
| OK | اختيار / إيقاف وتشغيل |
| رجوع | رجوع (مرتين في الشاشة الرئيسية = خروج) |
| ▲ ▼ أثناء البث المباشر / CH+ CH- | القناة التالية / السابقة |
| ◀ ▶ أثناء الفيلم | ترجيع / تقديم 10 ثواني |
| ⏪ ⏩ | 30 ثانية |
| الزر الأحمر | إضافة/إزالة من المفضلة |

### لو القنوات مش شغالة على الشاشة
من **الإعدادات** غيّر صيغة البث المباشر بين `HLS (m3u8)` و `MPEG-TS (ts)` — أغلب شاشات VIDAA بتشتغل أفضل مع **m3u8**.

## 2) نسخة الموبايل (APK)

### تحميل جاهز
كل `push` للمستودع بيشغّل **GitHub Actions** ويبني الـ APK تلقائياً:
`Actions` ← آخر تشغيل لـ **Build Xtream Player APK** ← من أسفل الصفحة حمّل **XtreamPlayer-apk**.
فك الضغط، انقل `XtreamPlayer.apk` للموبايل، وثبّته (فعّل "التثبيت من مصادر غير معروفة").

### البناء على جهازك
محتاج Node.js 18+ و JDK 21 و Android SDK (أسهل حاجة تنزّل Android Studio):
```bash
cd xtream-player
npm install
npm run apk
# الملف: android/app/build/outputs/apk/debug/app-debug.apk
```
أو افتح مجلد `android` في Android Studio واعمل Run.

## هيكل المشروع
```
xtream-player/
├── www/                  ← التطبيق نفسه (مشترك بين الشاشة والموبايل)
│   ├── index.html
│   ├── css/app.css
│   └── js/
│       ├── api.js        ← Xtream API (player_api.php)
│       ├── nav.js        ← التنقل بالريموت
│       ├── player.js     ← المشغل (hls.js على الشاشة / ExoPlayer على أندرويد)
│       ├── storage.js    ← الحسابات والمفضلة والإعدادات
│       └── app.js        ← الواجهة
├── proxy/server.js       ← سيرفر الشاشة + البروكسي (بدون مكتبات)
├── android/              ← مشروع أندرويد (Capacitor)
│   └── app/src/main/java/com/xtream/player/
│       ├── PlayerActivity.java      ← مشغّل ExoPlayer
│       └── NativePlayerPlugin.java
└── capacitor.config.json
```
